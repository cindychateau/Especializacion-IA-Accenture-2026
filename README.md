Las actividades CORE son **obligatorias** para el módulo. Para acceder al examen final, deberán completar al menos el **90%** de estas.

Las clases se realizarán a través de **Zoom**. Les recomendamos descargar e instalar la aplicación con anticipación para evitar inconvenientes al momento de conectarse.

## 📚 Sobre el curso

Este programa proporciona una formación completa en **Desarrollo con IA Generativa**, cubriendo desde la habilitación técnica y el consumo de APIs hasta la orquestación de agentes con RAG, y la integración profesional con servicios expuestos. El programa está diseñado para equipar a los estudiantes con las habilidades necesarias para desarrollar aplicaciones generativas completas (*end-to-end*), contenerizadas y listas para producción, utilizando herramientas como **Python, LangChain, FastAPI y Docker** para la implementación.
